El reto

Vender en línea sin pagar una plataforma cada mes

Un emprendedor necesita una tienda que cobre en pesos, emita factura y que pueda manejar sin ayuda. Las plataformas extranjeras cobran en dólares y no resuelven la factura colombiana.

Para el comprador

  • Catálogo con filtros por categoría, precio y marca.
  • Carrito, cupones y descuentos automáticos.
  • Pago en línea, transferencia o contra entrega.
  • Cuenta con historial y beneficios de cliente fiel.

Para el dueño de la tienda

  • Resumen de ventas y alertas de inventario.
  • Productos, fotos, opciones y existencias.
  • Pedidos con estados, de pendiente a entregado.
  • Promociones, cupones y programa de clientes fieles.

Lo que pide Colombia

  • Precios en COP con IVA incluido por producto.
  • Datos para factura: CC, NIT, consumidor final.
  • Pagos con Wompi: tarjeta, PSE y Nequi.
  • Facturación electrónica ante la DIAN.

Por dentro

Arquitectura simple, decisiones deliberadas

Un proceso de Node, una base SQLite por cliente y nada que compilar: se instala con Docker y se respalda con un comando.

Navegador

  • Tienda y panel en una SPA con rutas #/
  • JavaScript y CSS puros, fuentes locales
  • Temas por variables CSS
⇄

Servidor Node 22

  • API pública y de administración
  • Precios compartidos con el navegador y recalculados al comprar
  • Wompi, correo y cola de facturas
→

SQLite

  • node:sqlite en modo WAL
  • Un archivo por cliente
  • Migraciones numeradas y respaldos

Cada instalación se publica con un túnel de Cloudflare (cloudflared): el servidor no abre puertos y el dominio queda en la cuenta del cliente.

Una instalación por cliente

Datos, dominio y configuración aislados. Sin un sistema multiempresa que complique la seguridad.

La demo es el mismo código

El servidor real corre dentro del navegador: SQLite compilado a WebAssembly y la red reemplazada por llamadas locales. Lo que ves en la demo es lo que se instala.

Pagos con Wompi

Checkout firmado, webhook con verificación de firma, monto y moneda, y consulta del estado real al volver. Las llaves viven solo en variables de entorno.

Facturación electrónica

Documento, numeración por resolución, cola de envío y proveedores intercambiables. El envío a la DIAN depende del proveedor tecnológico que se elija.

Seguridad

Contraseñas con scrypt, sesiones con hash en la base, cookies HttpOnly, CSP estricta, límites de intentos y verificación de origen.

Probado

39 pruebas automáticas sobre precios, promociones, pedidos, Wompi y facturación con node --test.
